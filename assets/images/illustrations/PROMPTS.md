# FitNyx illustration system

Generated with the built-in image_gen tool. PNG sources retain transparency. Native vector companions live in src/components/art. Keep functional text outside artwork.

## Shared generation prompt

Use case: illustration-story. Production asset for FitNyx, a premium fitness mobile app. Warm, minimal editorial contour illustration with confident rounded mint-green outlines (#5FC793), dark forest-green filled accents, a little pale mint (#D9F7E7), generous transparent negative space. Sophisticated, friendly, softly organic, not glossy 3D, not stock photography, not neon cyberpunk. Thick enough linework to read at 160px. Centered complete composition with 12% clear margin, no text, no letters, no numbers, no UI, no watermark. True transparent background; all important shapes have visible outlines so they work on both near-black and light surfaces.

## Filo

Warm non-human mint seed character; leaf tuft, dark forest eyes, gentle smile, waving arm and forest-green scarf. Adult-friendly, compact silhouette. The small vector mark intentionally simplifies the face for navigation. Full character is used for welcome surfaces.
